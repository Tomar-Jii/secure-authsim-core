## 🛡️ Overview
Security simulation engine built to stress-test authorization barriers, detect JWT entropy weaknesses, and simulate complex authentication attacks.

## ⚡ Key Modules
* **Token Entropy Analysis:** Identifies weak cryptographic signatures.
* **Rate-Limit Resilience:** High-throughput stress generator validating server bounds.
* **Zero-Leak Pipeline:** Real-time auditing for OAuth2 and session handlers.
